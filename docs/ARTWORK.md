This repository does not currently grant an open-source license. Public availability alone does not grant permission to reuse the code or artwork.

`assets/FocusedBreakIcon.png` is generated dog-and-coffee artwork created for this app, using the supplied break GIF as a visual reference.

`assets/HaveABreak-original.gif` was supplied by the project owner. `Sources/EventHorizon/HaveABreak.gif` is an enlarged, smoothed derivative retaining the animation timing and transparency. `scripts/upscale-break-gif.sh` documents the transform; enlargement does not recover original detail.

The dog resembles Snoopy. The original animation's creator and reuse license have not been established.
